# 页面职责

状态：页面划分建议，尚未实现。更新：2026-11-17。
业务范围见 [V1 流程](v1-workflow.md)，数据见 [核心数据](data.md)。

| 使用者 / 页面 | 展示与输入 | 操作与结果 |
| --- | --- | --- |
| 学生 / 商品浏览 | 在售商品名称、价格、介绍；选择数量 | 进入订单确认；无须额外拆独立购物车 |
| 学生 / 订单确认 | 商品、数量、金额、固定配送信息；必填手机号、可选备注 | 核对后提交，云端重新校验；失败保留输入并提示原因 |
| 学生 / 提交结果 | 订单编号、已提交提示、未接入支付说明 | 仅表示订单保存成功，不展示“支付成功”；可作为确认页结果状态 |
| 经营者 / 商品管理 | 商品列表、上下架状态；名称、价格、介绍等编辑项 | 新增、编辑、上架、下架；编辑表单可复用同页 |
| 经营者 / 订单列表与详情 | 已提交订单、商品数量、手机号、备注、金额及配送信息 | 查看订单，为后续备货提供信息；不默认增加取消、退款或配送状态流转 |

管理入口根据身份展示，云端仍独立鉴权。订单信息不允许公开查询；学生只能取得自己订单的提交结果，经营者可以读取管理所需订单。

V1 暂不增加个人中心、地址簿、优惠券、路线选择、配送批次或支付页面。页面拆分和视觉样式不属于已确认业务规则。
